# The World Plan overrides the seeds

A versioned World Plan declares what exists where, and seeds supply only natural detail, so a required mountain range never depends on finding a lucky seed. The maximum extent is fixed up front because automatically routed Rivers, if ever added, depend on terrain far beyond a single Chunk, and only the Chunks that are asked for get generated. The World Seed does not change after the first publication, since that would alter every unlocked Chunk; later changes go through the World Plan and Region Seeds.
