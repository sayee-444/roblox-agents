# A world's size changes only by the developer's order

ADR 0002 fixed the maximum extent up front, and doubling a map by hand then took 160 changed lines, so issue #53 asked for `scale`, which multiplies a World Plan's extent, positions, lengths and heights and keeps its seeds. This supersedes that sentence of ADR 0002: the World Plan still declares the extent, and it changes only by the developer's order, followed by a `run` that rewrites every Chunk, because a new size changes what every Chunk holds. A world with Locked Chunks refuses it, since they would no longer fit, and a smaller world leaves the Chunks outside its extent as they are until the developer orders a wipe. Automatically routed Rivers, the reason ADR 0002 gave, do not exist yet, and if they are added they must read the extent the plan declares at that moment.
